# Migrating To uv

## Before Migrating

- list the current install, sync, test, and release commands
- identify lockfile and environment expectations in CI

## During Migration

- move local developer workflow and CI together
- document uv equivalents for the old commands
- remove redundant tooling once confidence is established

## After Migration

- keep one supported workflow
- update onboarding and setup docs
- verify editors and automation use the same environment rules
