## Python Development

This plugin bundles Python-focused agents, commands, and reusable skills for production services, libraries, APIs, and internal tooling.

## Contents

- `agents/`: Python and FastAPI advisors for implementation, debugging, and production hardening.
- `commands/`: orchestrated workflows for reviewing Python code and scaffolding new Python work.
- `skills/`: reusable guidance for code style, testing, packaging, reliability, configuration, and operations.

## Focus Areas

- readable, explicit, maintainable Python code
- safe project structure, packaging, and dependency management
- testing, error handling, and resource management
- performance, observability, and resilience
- backend service patterns including FastAPI and background jobs
