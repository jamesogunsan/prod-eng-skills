# Security Compliance

This plugin bundles agents, commands, and reusable guidance for security review, compliance gap assessment, control mapping, remediation planning, and audit-ready evidence preparation.

## Contents

- `agents/`: local agents for security and compliance review work
- `commands/`: orchestrated workflows for compliance and control assessments
- `skills/`: reusable guidance for scoped reviews, control mapping, and evidence collection

## Focus Areas

- Security and compliance gap reviews for applications and platforms
- Control mapping across common frameworks such as SOC 2, ISO 27001, PCI DSS, HIPAA, and GDPR
- Risk-based remediation planning instead of checkbox-only compliance work
- Audit evidence collection and documentation readiness
- Practical trade-offs across security, operability, delivery speed, and cost

## Use These Repo Skills In OpenCode

From the repository root, install a skill from this repo with `npx openskills install <skill-path>`.

Examples:

```bash
npx openskills install ./plugins/security-compliance/skills/compliance-review
```
