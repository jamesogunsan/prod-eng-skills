# Control Review Checklist

Use this checklist to review the most important security and compliance control areas.

## Identity and Access

- Least-privilege access for users, services, and automation
- Joiner, mover, and leaver process coverage
- MFA, privileged access control, and credential rotation

## Data Protection

- Encryption in transit and at rest
- Secrets storage and key management
- Data retention, deletion, and backup handling

## Change and Delivery Controls

- Change approval and traceability
- Separation of duties where required
- CI/CD safeguards, review gates, and deployment audit trails

## Monitoring and Response

- Logging for security-relevant actions
- Alerting, escalation, and incident handling readiness
- Periodic access review and control review cadence

## Documentation and Governance

- Policies mapped to actual operating practices
- Clear control ownership
- Evidence that is current, reviewable, and reproducible
