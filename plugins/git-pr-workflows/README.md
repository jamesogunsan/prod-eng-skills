# Git PR Workflows

This plugin bundles local agents and commands for production-safe code review, commit planning, pull request quality, and practical git workflow support.

## Contents

- `agents/`: local agents for code review, change-risk analysis, branch planning, and pull request workflow support
- `commands/`: workflows for git review, pull request improvement, and contributor onboarding

## Focus Areas

- Pre-commit and pre-PR quality review
- Commit message and branch workflow guidance
- Pull request clarity, risk communication, and review readiness
- Team onboarding into repository and review practices
- Safer rollout, rollback, and reviewer coordination for production-facing changes
