# Application Performance

This plugin bundles agents, commands, and skills for application profiling, APM rollout, observability, frontend performance, and Mendix-specific performance reviews.

## Contents

- `agents/`: local agents for performance, observability, and frontend optimisation
- `commands/`: phased performance review and optimisation workflows
- `skills/`: reusable performance and APM implementation guidance

## Focus Areas

- End-to-end application performance analysis
- OpenTelemetry-first APM design
- Uptrace-aware APM selection and implementation
- Safe performance optimisation for services, APIs, and user journeys
- Mendix performance best practices for domain models, microflows, pages, XPath, and OQL

## Use These Repo Skills In OpenCode

From the repository root, install a skill from this repo with `npx openskills install <skill-path>`.

Examples:

```bash
npx openskills install ./plugins/application-performance/skills/apm-implementation
```
